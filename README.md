# Kadam Shiva Shankar – Portfolio

**Live site:** [https://shivakadam22.com](https://shivakadam22.com)

## Overview

A multi-page personal portfolio for Kadam Shiva Shankar, a Data Science Engineer working on machine learning, NLP, and AI voice agents, and a B.Tech Computer Science student in Hyderabad. The site presents his experience, projects, skills, education, and contact details in a clean blue-themed design.

## Pages

| Page | What's on it |
|---|---|
| **Home** | Introduction, focus areas (NLP & intent detection, data pipelines, evaluation & analytics), and highlights |
| **Experience** | Data Science Engineer at Neostechus and AI Annotation Specialist at Student Tribe |
| **Projects** | Hospital Management System, Diabetes Prediction, and Offline ChatGPT Assistant |
| **Skills & Contact** | Tech stack, education, spoken languages, and ways to get in touch |

## Features

- Multi-page layout with a shared navigation menu
- Project cards that expand on click to show purpose, technologies, and results
- Filters on the Projects page to switch between AI / ML and Software work
- Click animations and a blue color palette for a professional look
- Direct links to live project demos, GitHub, and LinkedIn
- "Open to opportunities" status and a contact section with email and LinkedIn

## Featured Projects

- [**Hospital Management System**](https://hospital-management-systemm-gamma.vercel.app/): manages patient records, appointments, and daily hospital operations (Python, Java, SQL, HTML, CSS)
- [**Predicting Diabetes Using Machine Learning**](https://diabetes-prediction-ochre-xi.vercel.app/): predicts diabetes from patient health data and medical parameters (Python, Machine Learning)
- **Offline ChatGPT Assistant**: an offline AI chatbot that answers queries in local languages without internet access

## Deployment

- **Source:** GitHub repository
- **Hosting:** Vercel, with automatic deploys on every push to the main branch
- **Domain:** `shivakadam22.com`, registered on GoDaddy and connected to Vercel

## Customize

- **Content:** update the text for experience, projects, skills, and contact details in the page files
- **Projects:** add a new project card to the Projects page and set its category (AI / ML or Software) so the filters pick it up
- **Colors:** the palette runs from deep navy (`#000f22`) to light sky blue (`#c0e6fd`); adjust it in the site's stylesheet
