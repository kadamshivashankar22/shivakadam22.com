# Kadam Shiva Shankar — Portfolio

Static multi-page portfolio (HTML, CSS, JS). No build step. Live at https://shivakadam22.com

## Pages
- `index.html` — Home
- `experience.html` — Experience
- `projects.html` — Projects
- `skills.html` — Skills, education and contact

## Run locally
```bash
npx serve .
```
Then open the address it prints.

## Deploy
Push to GitHub, import the repo in Vercel (framework preset: Other), then add the domain `shivakadam22.com` in Project Settings → Domains.
